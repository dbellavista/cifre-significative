# Documentation map

| document | what it is | maintained |
|---|---|---|
| [`../README.md`](../README.md) | how to run the pipeline, notebooks and dashboard | by hand |
| [`data_catalog.md`](data_catalog.md) | every indicator with source, dataset code, filters and coverage | generated: `uv run python scripts/make_data_catalog.py` |
| [`data_dictionary.md`](data_dictionary.md) | table schemas, units, coverage limits, known anomalies | by hand |
| [`manual_data.md`](manual_data.md) | how to hand-enter PISA 2022, PIAAC and procurement series | by hand |
| [`literature/`](literature/) | papers consulted (`papers.csv`) and the theme -> hypothesis -> indicator map | by hand |
| [`../reports/findings.md`](../reports/findings.md) | main findings with numbers and caveats | by hand, after each analysis round |
| [`methodology.md`](methodology.md) | how we approach the work and the statistical/mathematical foundation: principles, funnel, FDR, permutation and placebo inference, panel, spatial, time-series and fiscal methods, limits | by hand |
| [`analysis_framework.md`](analysis_framework.md) | the correlation discovery framework (national, regional, monthly/quarterly): funnel, experiments, safeguards, limits | by hand |
| `../src/cifresignificative/dashboard/` | Streamlit dashboard (`uv run streamlit run src/cifresignificative/dashboard/app.py`); chart builders in `charts.py`, views in `app.py` | by hand |
| `../tasks/` | invoke tasks: `uv run inv --list` (ruff + ty checks, scoped tests, data-catalog freshness) | by hand |
| `../notebooks/01..42` | analysis notebooks with takeaways | generated: `scripts/make_notebooks.py` from `scripts/notebook_cells.py` (rewrites only notebooks whose cells changed; `--force` or names to override; re-execute those it reports) |
| `../reports/figures/` | exported charts | generated by the notebooks |
| `../publish/`, `../scripts/export_public.py` | allowlist (`manifest.toml`), templates and script that build the public repo from this private one | by hand |

When data change: re-run `fetch`, `build`, `uv run inv docs.catalog`, regenerate and execute the notebooks, then update `reports/findings.md`.
